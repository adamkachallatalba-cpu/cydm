CYDM WEBSITE STARTER PACKAGE

Files:
- index.html: responsive website and membership form
- thank-you.html: confirmation page
- logo.svg: standalone vector logo

IMPORTANT:
1. This is a website starter package, not a live published website.
2. The membership form is configured for Netlify Forms. To collect submissions online:
   - Create a Netlify account.
   - Deploy this folder/site to Netlify (drag-and-drop deploy is available in the Netlify dashboard).
   - After deployment, open the site's Forms section and confirm form detection is enabled.
   - Submit a test application and verify it appears in the dashboard.
3. Add an official phone number and email address before publishing.
4. CYDM is marked as proposed/not yet registered. Keep this wording until legal registration is complete.
5. Treat members' personal information securely; restrict dashboard access to authorised officers and publish an appropriate privacy notice.
6. For a custom domain, purchase/register it through a domain provider and connect it in Netlify settings.
